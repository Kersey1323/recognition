# 配件360度全景采集工装软件方案

## 一、背景与目标

为配合3D重建产线，需要一套运行在 Windows 11 工控机上的工装软件，控制采集设备（摄像头、转盘/机械臂）对配件做360度视频拍摄，拍完后上传到服务器触发3D重建和特征提取。

技术栈：**Tauri 2.x + Vue 3 + TailwindCSS**

选 Tauri：包体积小（~10MB）、内存占用低、Rust 后端直接走串口/USB，Win11 自带 WebView2 免装运行时。

---

## 二、功能模块

四个主要模块：

| 模块 | 核心功能 |
|------|---------|
| 设备控制 | 转盘启停/调速、灯光开关、设备状态监测 |
| 视频采集 | 摄像头预览、录制控制、视频回放 |
| 任务管理 | 从后端拉取配件列表、选择配件、采集记录、上传管理 |
| 系统设置 | 服务器地址、串口参数、摄像头配置、存储路径 |

---

## 三、采集流程

```
1. 从系统中选择待采集的配件（后端接口拉取配件列表，按物料编码检索）
       ↓
2. 点击"开始采集"
       ↓
3. [自动] 补光灯开启 → 转盘启动 → 摄像头录制
       ↓
4. [自动] 转盘完成360° → 停止录制 → 灯光关闭
       ↓
5. 视频回放，操作员确认质量
       ↓
6. 确认提交 → 进入上传队列 → 后台上传到服务器
       ↓
7. 继续下一个配件
```

单件采集约 40~60秒，操作员每小时可完成 60~80件。

## 四、技术架构

```
┌─────────────────────────────────────────────────┐
│           Vue 3 + TailwindCSS (WebView2)        │
│                                                 │
│   采集界面    采集记录    上传管理    系统设置      │
└──────────────────┬──────────────────────────────┘
                   │ Tauri IPC
┌──────────────────┴──────────────────────────────┐
│                Tauri Rust 后端                    │
│                                                 │
│  设备驱动(serialport)   视频处理(ffmpeg)           │
│  网络通信(reqwest)      本地存储(sqlite)           │
└───────┬──────────────┬──────────────┬───────────┘
        │              │              │
   串口设备         摄像头          服务器
   转盘/灯光       USB/工业相机     REST API
```

**前端**：Vue 3 + Pinia 状态管理 + Vue Router，四个页面对应四个功能模块。

**后端**：Rust 负责串口通信、视频采集、分片上传、本地SQLite存储。所有硬件操作走 Tauri Command 暴露给前端。

**与服务器交互**：
- 拉取配件列表：`GET /api/items`
- 上传视频：`POST /api/capture/upload`（分片上传）
- 查询重建进度：`GET /api/reconstruction/{task_id}/status`
