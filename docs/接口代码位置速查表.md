## 快速查找命令

### 查找接口路由定义
```bash
# 按路径查找
grep -rn "/index_rebuild" csrcqsf/services/

# 按方法名查找
grep -rn "def rebuild_parts_pic_index" csrcqsf/services/
```

### 查找业务逻辑实现
```bash
# 按方法名查找
grep -rn "def rebuild_pic_index" csrcqsf/biz/

# 按类名查找
grep -rn "class RailwayPartsManager" csrcqsf/biz/
```

### 查找数据模型
```bash
# 按表名查找
grep -rn "class SgoItemImages" csrcqsf/models/

# 按字段查找
grep -rn "is_indexed" csrcqsf/models/
```

## 使用IDE快速跳转

### VSCode
1. 在路由函数中，按住 `Ctrl` (Windows/Linux) 或 `Cmd` (Mac)
2. 点击业务方法名（如 `RailwayPartsManager.rebuild_pic_index()`）
3. 自动跳转到业务逻辑实现

### PyCharm
1. 右键点击方法名
2. 选择 "Go to Declaration" 或按 `Ctrl+B`
3. 自动跳转到实现位置
