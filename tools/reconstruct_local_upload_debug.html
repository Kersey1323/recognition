视频分片上传调试页

这个页面用于模拟真实的 partBuffer 上传流程。它不会把整文件直接发给 /upload/part，而是按后端返回的 part_size 用 file.slice(start, end) 切出每一段，再逐片上传。你可以切换 local 或 remote 模式，验证两种会话都走同一套 init -> part -> progress -> complete 流程。

配置

当前页面验证的是“前端先 file.slice(start, end) 切片，再把单片传给 /railway/parts/v2/reconstruct/video/upload/part”这个动作本身。
当上传会话为 storage_mode=local 时，服务端会先把分片落本地；当会话为 storage_mode=remote 时，服务端会立即把当前分片代理上传到 MinIO multipart upload。
两种模式都会由当前页面先用 file.slice() 切出单片，再调用你现有的 /upload/part 接口，不会直接把整文件提交到服务端。
